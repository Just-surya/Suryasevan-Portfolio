My Projects

Simple calculator

A simple calculator built using HTML and CSS focuses on creating the user interface, including buttons, layout, and display screen. HTML structures the calculator, while CSS styles it to make it visually appealing and responsive. To perform actual calculations like addition, subtraction, multiplication, and division, JavaScript is required. This project helps in understanding basic web development concepts such as layout design, user interaction, and event handling.

Username/Email Formatter

A username and email formatter is a simple web project built using HTML,Javascript and CSS for the interface, and JavaScript for functionality. It takes user input and formats it into a standardized structure—for example, converting text to lowercase, removing spaces, and generating a valid email format (like `username@gmail.com`). This project helps in understanding input handling, string manipulation, and basic form validation while also improving user experience by ensuring consistent and error-free data entry.
