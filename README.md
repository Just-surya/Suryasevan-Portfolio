# 🌐 Suryasevan's Developer Portfolio

A personal portfolio website built with vanilla **HTML**, **CSS**, and **JavaScript** — designed to showcase my skills, projects, and contact information with a clean dark-green aesthetic.

## ✨ Features

- 🧭 **Sticky Navigation Bar** — smooth scroll to each section
- 👤 **Hero Section** — profile photo, name, and tagline
- 🧠 **About & Skills** — personal bio + tech stack icons + soft skills
- 🗂️ **Projects Section** — card-based layout with hover animations
- 📬 **Contact Details** — email, LinkedIn, and phone
- 📩 **Contact Form** — powered by [EmailJS](https://www.emailjs.com/) for direct messaging
- 🌑 **Dark Theme** — deep navy background with glowing green accents
- 📱 **Responsive Design** — works across desktop and mobile

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| HTML5 | Structure & layout |
| CSS3 | Styling, animations, responsive design |
| JavaScript | Form logic, EmailJS integration |
| EmailJS | Contact form email delivery |
